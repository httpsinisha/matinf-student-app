# Theme 0.6.0 visual reference and assets

The layout and CSS are written for MATINF. The design reference is the College
demo at https://bootstrapmade.com/content/demo/College/; no template source code,
fonts, scripts or template image assets are bundled.

`assets/matinf-logo.png` is the user-provided MATINF logo.

`assets/students.jpg` is the existing learning/community image published on the
MATINF source website, downloaded from:
https://matinf.pmf.unibl.org/wp-content/uploads/2021/02/studenti1.jpg
It illustrates collaborative study; it is not presented as a named professor or
as a portrait of any of the student-story authors. Source attribution does not
establish an independent license to redistribute the photograph separately.

Program illustrations are CSS backgrounds and mathematical text symbols. All
news, notices, program names and links are supplied by WordPress. Sections for
student stories appear when that page is published.
